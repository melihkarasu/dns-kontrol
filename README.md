# 🌐 DNS Kontrol & Ağ Teşhisi

Cloudflare & Google DoH ile anlık A, MX, TXT, NS kayıtları, küresel yayılım, SPF/DMARC ve gecikme testi.

## ✨ Özellikler
- Tamamen istemci taraflı, sunucusuz çalışma.
- LocalStorage ile veri saklama.
- Mistral AI tasarım diliyle optimize edilmiş arayüz.

## 🚀 Hızlı Başlangıç
1. Bu repoyu klonlayın.
2. `index.html` dosyasını tarayıcıda açın.



## 🛠️ Teknik Detaylar
- **Styling:** Tailwind CSS
- **Design System:** Mistral AI Design System
- **Storage:** Browser LocalStorage API
- **API Source:** Google DNS / Cloudflare API
